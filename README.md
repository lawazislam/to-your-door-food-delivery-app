# To Your Door: An Android Application for Food Delivery

Bachelor's thesis project, Electronics & Communication Engineering, Institute of Engineering & Management, Kolkata (2020-2024), supervised by Prof. Tapan Kumar Rana.

## Team project

Four-person capstone: Ishu Kumar, Lawaz Islam, Anchal Kumari, and Arko Paul. My own contribution was spread across the app rather than owned as one isolated piece, UI screens, backend integration, and the rest of the build were worked on together as a team, not divided into strict individual lanes.

## What this covers

An Android food delivery app concept and build, covering both the customer side (restaurant discovery, menu browsing, cart and checkout, real-time order tracking, order history) and the restaurant side (menu management, order handling). The report documents the full lifecycle: literature review, system design, implementation, and results.

**Tech stack** (per the thesis): Kotlin, Android Studio, Firebase, Google Maps API (location and tracking), Razorpay (payments), Git for version control.

## Why there's no source code in this repo

The thesis documents real development, its "Code Snapshots" section shows actual Android Studio screens with real project files (adapters, layout files, a working product-listing UI), so this was genuinely built, not just planned. But that code exists only as screenshots inside the PDF, not as separate, extractable source files, and the original Android Studio project isn't available to publish. Rather than reconstruct a multi-file Kotlin/Firebase app from a handful of screenshots, which would mean guessing at most of an app's actual structure, this repo holds the full written report as the accurate record of the project.

Full thesis: [`To_Your_Door_Thesis.pdf`](To_Your_Door_Thesis.pdf) in this repo.
